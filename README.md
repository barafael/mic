# mic

Video conferencing on [Media over QUIC](https://moq.dev): a native app for Windows, Linux and
macOS, end-to-end encrypted, through a MoQ relay.

Nothing works yet. [PLAN.md](PLAN.md) is the order of the work, and
[docs/design.md](docs/design.md) the design behind it.
